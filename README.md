LexiFlow (词流) · 极致的单文件背词神器

一款融合认知科学与 AI 大模型，无后端、零依赖的个人英语词汇工具。

· 🧠 科学记忆：基于遗忘曲线与自适应算法，在记忆临界点精准唤醒。
· 🤖 AI 伴侣：用户可通过api接入ai大模型，无可用自然语言跟ai对话即可让它自动加词、查数据。(需添加api才能解锁聊天功能)
· 🎧 流式语音：浏览器TTS 分句朗读，随时听写，解放双眼。
· 📚 词库：支持 TXT
(可找任意agent工具如workbuddy、trae制定和词汇整合成.txt文件格式）一键导入，A-Z 分页索引，千词渲染丝滑不卡顿。
· 🐾 像素桌宠：陪伴式复习小猫，答对冒星星，答错下雷雨，提供情绪价值。

🛡️ 隐私安全：所有词库与 API Key 100% 存储于本地浏览器，绝不上传云端。
🚀 极简启动：下载单个 HTML 文件，双击即用，或直接部署为网页/PWA。
